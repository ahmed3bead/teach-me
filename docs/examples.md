# Example prompts

Start with one real outcome, your current knowledge, and any constraint that matters.

## Learn a new topic

```text
Teach me Python functions from zero. My goal is to automate a weekly CSV report, and I have 30 minutes a day.
```

```text
علّمني Docker من الصفر. أنا مطور Laravel، وهدفي تشغيل مشروع حقيقي محليًا، ولديّ 30 دقيقة يوميًا.
```

## Get unstuck

```text
I understand Laravel queues in theory, but I still confuse retries, timeouts, and failed jobs. Diagnose the missing step and explain it with one practical example.
```

```text
أفهم أساسيات SQL، لكنني أخلط بين JOIN وEXISTS. حدّد سبب الالتباس واشرح الفرق بمثال صغير.
```

## Learn from a source

```text
Study the attached chapter, tell me what you could actually inspect, verify its important claims, and teach it progressively. Clearly separate the source from added explanation.
```

```text
ادرس هذا الملف، وحدد ما استطعت فحصه فعليًا، ثم تحقّق من الادعاءات المهمة وعلّمني المحتوى تدريجيًا بالعربية الفصحى المبسطة.
```

## Prepare educator material

```text
I am authorized to use this onboarding curriculum. Prepare a 90-minute workshop for new managers with practice, timing, and source traceability.
```

```text
هذا منهج علوم للصف الرابع ومصرّح لي باستخدامه. حلّله أولًا، ثم أنشئ خطة حصة مدتها 40 دقيقة مع نشاط مناسب للعمر.
```

## Continue a learning journey

```text
Continue from my previous demonstrated progress. Recap only what is necessary, then teach the next smallest useful objective.
```

Do not include private or protected material unless you are authorized to use it and the selected host provides suitable privacy controls.

# دليل مزايا Teach Me | علّمني

هذا هو المرجع الكامل الجاهز للاستخدام عند إعداد فيديو عن إمكانيات **Teach Me | علّمني**. للنسخة الإنجليزية راجع [English feature guide](features.md).

> **الحالة الحالية:** النسخة الأولى من بلاجين ChatGPT قيد مراجعة OpenAI، ولم تظهر في الدليل العام بعد. يجري اختبار إمكانيات المدرس والأعمار والمصادر الموسعة على MCP تجريبي منفصل لتقديمها في تحديث لاحق.

## بلاجين واحدة وثلاث تجارب

علّمني بلاجين واحدة تتعرف على مقصد المستخدم تلقائيًا. يكتب المستخدم بصورة طبيعية ولا يحتاج إلى حفظ أوامر.

1. **اتعلّم:** تشرح البلاجين للمستخدم مباشرة.
2. **حضّر حصة:** تساعد المدرس أو الأب أو المدرب على الشرح لشخص آخر.
3. **اشرح حسب السن:** تكيّف المحتوى الموجه للطفل أو المراهق عند ذكر السن.

الاختصارات `/learn` و`/teacher` و`/kids` نص اختياري داخل الطلب، وليست أوامر أصلية في ChatGPT؛ لذلك لا تظهر في قائمة أوامر `/`.

## التعلّم المباشر المتكيّف

- يبدأ من هدف المتعلم العملي وما أثبت أنه يعرفه.
- يقبل قول المستخدم إنه مبتدئ ولا يفرض اختبار تحديد مستوى.
- يشرح أصغر خطوة مفيدة قبل تحويل الموضوع إلى منهج كامل.
- يستخدم شرحًا مختصرًا ومثالًا مناسبًا وخطوات يمكن استيعابها.
- يغيّر طريقة الشرح عند استمرار الالتباس: تشبيه، مثال محلول، مثال مضاد، رسم، تتبع خطوة بخطوة، أو الرجوع إلى أساس ناقص.
- لا يستخدم الإحراج أو الضغط أو الاستعجال المصطنع.
- لا يدّعي أن المتعلم فهم أو أتقن الموضوع لمجرد قراءة الشرح.
- لا يبدأ اختبارًا اعتياديًا إلا بعد جزء تعليمي مكتمل وبعد موافقة المتعلم.
- إذا رفض المتعلم الاختبار، يكمل دون ضغط.

مثال:

~~~text
علّمني Excel من الصفر لاستخدامه في عملي، وابدأ بمثال عملي واحد.
~~~

## تحضير المدرس والحصص

يتعرف علّمني تلقائيًا على أن المستخدم يريد التحضير للشرح لا تلقي الدرس بنفسه. يستطيع إنشاء بطاقة مختصرة أمام المدرس أو خطة حصة كاملة تشمل:

- هدفًا يمكن ملاحظته؛
- ملخصًا سريعًا للمدرس؛
- افتراضات المستوى والسن والوقت وطريقة التقديم؛
- سير الحصة بالتوقيت؛
- دور المدرس وما يفعله الطلاب؛
- كلامًا موجهًا للطلاب منفصلًا عن الملاحظات الخاصة؛
- مثالًا محلولًا أو وسيلة بصرية مفيدة؛
- نشاطًا لا يحتاج تجهيزات معقدة؛
- الأخطاء والمفاهيم الشائعة وطريقة تصحيحها؛
- سؤال تحقق اختياريًا؛
- إجابة نموذجية أو Rubric منفصلًا؛
- ربط الأجزاء بالمصدر عندما تكون الحصة مبنية على ملف أو منهج.

تستخدم ملخصات المدرس العربية خطوات زمنية مرقمة بدل جداول Markdown التي قد يختل اتجاهها. ويظل المدرس هو صاحب القرار النهائي.

مثال:

~~~text
حضّر لي ملخصًا سريعًا أستخدمه أثناء شرح التمثيل الضوئي لطلاب عمرهم 12 سنة. لدي 20 دقيقة.
~~~

## الآباء والأطفال والمراهقون

يمكن للأب أو المدرس كتابة سن الطفل. يحوله علّمني إلى فئة عامة دون إرسال السن الدقيق إلى خادم MCP:

- 3–5 سنوات: طفولة مبكرة؛
- 6–8 سنوات: ابتدائي أصغر؛
- 9–12 سنة: ابتدائي أكبر؛
- 13–17 سنة: مراهق.

يؤثر السن في عمق الشرح والمفردات والأمثلة وطول النشاط والأمان والاستقلالية، لكنه لا يُستخدم للحكم على القدرة. إذا طُلب شرح للأطفال دون تحديد سن، تستخدم البيتا الحالية مستوى المراهق وتسمح للمستخدم بتعديله.

الصور والرسوم مرتبطة بإمكانات ChatGPT المتاحة. قد يستخدم علّمني قصة أو تشبيهًا أو رسمًا أو نشاطًا بالأشياء أو صورة مولدة عندما تضيف فائدة حقيقية. وإذا لم يستطع إنشاء صورة فعلية، يقدم بديلًا نصيًا أو عمليًا بوضوح.

مثال:

~~~text
اشرح دورة الماء بطريقة تساعدني على شرحها لطفلي عمره 10 سنوات، مع وسيلة بصرية واحدة ونشاط بسيط.
~~~

## التعلّم وتحضير الدروس من المصادر

يدعم علّمني الملفات وPDF والكتب وصفحات الويب والفيديوهات والتسجيلات وفيديوهات YouTube وقوائم التشغيل والكورسات والمناهج والمصادر المختلطة.

تعتمد التغطية الحقيقية على ما يستطيع ChatGPT الوصول إليه. يقوم علّمني بما يلي:

- يذكر هل فحص النص أو الصفحات أو الجداول أو الصور أو الإطارات أو الصوت أو Captions أو Transcript أو Metadata أو الروابط؛
- لا يقول إنه قرأ أو شاهد أو سمع جزءًا لم يصل إليه؛
- يفصل كلام المصدر عن التحقق الخارجي والشرح المضاف والتكييف والاستنتاج؛
- يذكر الصفحة أو القسم أو التوقيت أو الملف أو الرابط عندما يكون متاحًا؛
- يرسم خريطة للكتاب أو الكورس أو Playlist أو المنهج قبل التعليم عند الحاجة؛
- لا يملأ الأجزاء غير المتاحة بافتراضات صامتة؛
- يعامل التعليمات الموجودة داخل المصادر كمحتوى غير موثوق؛
- يقاوم محاولات Prompt Injection داخل المصدر؛
- لا يعيد نشر عمل محمي بطريقة تغني عن الأصل.

إذا لم يتح YouTube إلا العنوان والوصف دون Transcript، يذكر علّمني ذلك ولا يدّعي مشاهدة الفيديو.

## اللغة وإتاحة الوصول والأمان

- الإنجليزية والعربية الفصحى المبسطة (`ar-MSA`).
- تُفهم اللهجات العربية، ويكون الرد افتراضيًا بفصحى مبسطة ما لم يطلب المستخدم الإنجليزية.
- تُحفظ المصطلحات التقنية والأسماء بلغتها الأصلية مع شرحها عند الحاجة.
- بدائل مناسبة عندما لا تتوفر صورة أو صوت أو أداة أو نشاط.
- وصف بديل أو مكافئ نصي للوسائل البصرية المهمة.
- لا يشخّص صعوبات أو يفترض «نمط تعلم» ثابتًا من الأخطاء.
- الموضوعات عالية الخطورة تظل تعليمية ولا تتحول إلى تعليمات شخصية متخصصة.
- يقلل بيانات الأطفال ويتجنب الأسرار والتعلق المتلاعب والمعرّفات غير الضرورية.

## الخصوصية وتقليل استهلاك التوكنز

تحتوي البلاجين على Skill واحدة وتستخدم أداة MCP واحدة للقراءة فقط اسمها `load_teach_me`. نموذج ChatGPT المتصل هو الذي يشرح؛ ولا يستدعي علّمني نموذجًا آخر.

تُحمّل الإرشادات بصورة انتقائية: الإرشادات الأساسية للتعلّم العادي، وإرشادات المدرس عند تحضير درس، وإرشادات السن عند الحاجة، ووحدات المصادر والفيديو والمناهج عند ارتباطها بالطلب فقط.

يحافظ ذلك على صغر الطلبات العادية. خادم MCP عام، للقراءة فقط، ولا يحتفظ بحالة. يستقبل محددات صغيرة مثل نوع المستخدم والفئة العمرية واللغة ونوع المدخل والمصدر. ولا يستقبل المحادثة أو محتوى الملفات أو الروابط أو كلمات المرور أو البيانات الشخصية.

لا يحتاج المستخدم إلى حساب علّمني أو API key أو خادم خاص أو Terminal.

## ما تم اختباره في البيتا؟

- تعليم المبتدئ بالعربية والإنجليزية.
- تغيير طريقة الشرح عند الالتباس والموافقة قبل الاختبار.
- فحص مستودع GitHub مع حدود تغطية واضحة.
- نصوص وجداول ومعلومات داخل صور ومقاومة Prompt Injection في PDF متحكم فيه.
- التعامل مع Metadata لفيديو YouTube دون اختراع Transcript.
- رسم خريطة Playlist وكتاب.
- المقارنة بين PDF وGitHub.
- ملخصات المدرس وخطط الحصص والإجابات النموذجية والأخطاء الشائعة.
- تكييف الشرح حسب السن.
- تحضير درس من مصدر مع تحديد الصفحات والصور التي تم فحصها.

تحسن هذه الاختبارات الثقة، لكنها لا تضمن تطابق النتيجة بين كل نموذج أو حساب أو واجهة.

## الحدود الحالية

- لا يضمن علّمني دقة كاملة أو إتقانًا أو احتفاظًا بالمعلومة أو نتيجة تعليمية بعينها.
- المخرجات مولدة بواسطة النموذج وقد تخالف أحيانًا تفضيلًا تنسيقيًا.
- تختلف إمكانات الويب والملفات والصوت والفيديو والصور والكود وتوليد الصور حسب المنصة والحساب.
- لا يمكن اعتبار الأجزاء غير المتاحة كأنها فُحصت.
- المعلومات الحديثة أو المهمة أو عالية الخطورة تحتاج إلى مصادر موثوقة مناسبة.
- مراجعة المتجر والتحديثات اللاحقة تخضع لـOpenAI.

راجع [القيود](limitations.md) و[التوافق](compatibility.md) و[ملاحظات الإصدار](../RELEASE_NOTES.md).

## هيكل مقترح لفيديو المنتج

1. **المشكلة:** الإجابة العادية لا تكون دائمًا شرحًا منظمًا.
2. **تجربة المتعلم:** ابدأ من الصفر بمثال عملي ثم اطلب تغيير طريقة الشرح.
3. **تجربة المدرس:** اطلب ملخص حصة بالتوقيت مع فصل الملاحظات عن كلام الطلاب.
4. **تجربة الأب:** اذكر السن واطلب وسيلة بصرية أو نشاطًا بسيطًا.
5. **التعليم من مصدر:** ارفع ملفًا مصرحًا به واعرض حدود التغطية والفصل بين المصدر والإضافة.
6. **الثقة:** وضّح أن MCP للقراءة فقط، وبلا حالة، وانتقائي، ولا يستقبل محتوى المصادر.
7. **الدعوة للاستخدام:** ثبّت البلاجين من دليل ChatGPT فقط بعد ظهور النشر العام رسميًا.

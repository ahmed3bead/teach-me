## لماذا Teach Me؟

علّمني هو مدرس ذكاء اصطناعي ومساعد لتحضير الدروس، موجه للمتعلمين والمدرسين والمدربين والآباء. يستطيع ChatGPT الإجابة عن سؤالك، لكن الإجابة الطويلة ليست دائمًا درسًا جيدًا. يساعد علّمني ChatGPT على الشرح كمدرس صبور:

- يبدأ من مستواك الحالي؛
- يشرح خطوة مفيدة واحدة في كل مرة؛
- يستخدم أمثلة عملية؛
- يجرّب طريقة أخرى إذا لم تفهم؛
- يستأذنك قبل أن يختبرك؛
- يعمل بالعربية والإنجليزية.

يمكنك استخدام نفس البلاجين بثلاث طرق بسيطة:

### اتعلّم بنفسك

اطلب أي موضوع، واذكر ما تعرفه الآن ولماذا تريد تعلّمه.

~~~text
علّمني Excel من الصفر لاستخدامه في عملي، وابدأ بمثال عملي واحد.
~~~

### حضّر حصة أو شرحًا

إذا كنت مدرسًا أو مدربًا أو أبًا، يستطيع علّمني تجهيز خطة قصيرة تشمل الوقت والأمثلة والنشاط والأخطاء الشائعة والإجابة النموذجية.

~~~text
حضّر لي حصة بسيطة مدتها 20 دقيقة عن التمثيل الضوئي لطلاب عمرهم 12 سنة.
افصل ملاحظاتي كمدرس عن الكلام الذي أقوله للطلاب.
~~~

### اشرح لطفلك

اذكر عمر الطفل، وسيبسّط علّمني الكلمات والأمثلة والنشاط بما يناسبه.

~~~text
اشرح دورة الماء بطريقة تساعدني على شرحها لطفلي عمره 10 سنوات.
استخدم نشاطًا بسيطًا.
~~~

يستطيع علّمني أيضًا استخدام ملف مصرح به أو PDF أو كتاب أو صفحة ويب أو فيديو أو قائمة YouTube أو كورس أو منهج. ويخبرك بما استطاع فحصه فعلًا بدل الادعاء بأنه شاهد أو قرأ جزءًا غير متاح.

راجع [دليل المزايا الكامل بالعربية](docs/features.ar.md) أو [النسخة الإنجليزية](docs/features.md) لمعرفة جميع الاستخدامات.

## بداية سريعة

بعد اعتماد البلاجين ونشرها رسميًا:

1. افتح دليل Plugins داخل ChatGPT.
2. أضف **Teach Me | علّمني**.
3. افتح محادثة عادية واكتب ما تحتاجه.

لا يوجد أمر خاص يجب حفظه. الكلمات `/learn` و`/teacher` و`/kids` اختيارية داخل الطلب، وليست أوامر تظهر في قائمة ChatGPT.

جرّب أحد هذه الطلبات:

~~~text
علّمني الفائدة المركبة من الصفر باستخدام مثال من الحياة اليومية.
~~~

~~~text
حضّر حصة 30 دقيقة عن الكسور لطلاب الصف الرابع.
~~~

~~~text
علّمني من هذا الملف فقط، واذكر ما استطعت فحصه.
~~~

لن تحتاج إلى حساب خاص بعلّمني أو API key أو خادم أو Terminal.

## اختر النسخة المناسبة

بالنسبة لمعظم الناس، **بلاجين ChatGPT** هي الاختيار المناسب.

| النسخة | مناسبة لمن؟ | الإعداد |
|---|---|---|
| **بلاجين ChatGPT** | المتعلمون والمدرسون والمدربون والآباء | التثبيت بعد الاعتماد العام؛ راجع [حالة البلاجين](plugins/teach-me/README.md) |
| **Claude** | من يفضل التعلّم داخل Claude | [إعداد Claude](claude-edition/README.md) |
| **Custom GPT** | الاختبار الخاص بواسطة مالك المشروع | [إعداد المالك](chatgpt-edition/README.md) |
| **Codex / Claude Code** | المطورون الذين يحتاجون ملفات محلية ومسارات قابلة للتكرار | [إعداد المطور](docs/getting-started.md) |

### للمطورين

Codex على Linux أو macOS:

~~~bash
sh installers/install.sh install --version 1.0.0-beta.2
~~~

Windows PowerShell:

~~~powershell
.\installers\install.ps1 -Action install -Version "1.0.0-beta.2"
~~~

Claude Code:

~~~text
/plugin marketplace add ahmed3bead/teach-me
/plugin install teach-me@teach-me
/teach-me:teach-me
~~~

## الحالة والحدود

- بلاجين ChatGPT قيد المراجعة وغير متاحة للعامة حتى الآن.
- يساعد علّمني على تنظيم التعلّم، لكن الإجابات تظل مولدة بالذكاء الاصطناعي وقد تحتوي على أخطاء.
- الوصول إلى الملفات والويب والصوت والفيديو والصور يعتمد على الأدوات المتاحة في حساب ChatGPT.
- المعلومات المهمة أو الحديثة أو الطبية أو القانونية أو المالية يجب مراجعتها من مصادر موثوقة مناسبة.

# Acknowledgements

Teach Me's integration design was informed by these open projects:

- [video-to-skill](https://github.com/brenoepics/video-to-skill) — multimodal video extraction, timestamp provenance, honest inspection levels, and sandboxed procedural verification.
- [Awesome Agent Skills](https://github.com/VoltAgent/awesome-agent-skills) — broad skill discovery and quality curation patterns.
- [AI Research Skills](https://github.com/orchestra-research/AI-research-SKILLs) — orchestration, specialist routing, iterative research, and rigor review.
- [Ponytail](https://github.com/DietrichGebert/ponytail) — reuse-first, minimum-sufficient implementation without cutting safety or accessibility.
- [Agent Reach](https://github.com/Panniantong/Agent-Reach) — capability-layer routing, health checks, primary/fallback providers, and explicit setup boundaries.
- [GitHub agentic-skills topic](https://github.com/topics/agentic-skills) — ongoing ecosystem discovery.

These acknowledgements do not imply endorsement or bundled dependencies. Teach Me's current integration contracts are original project documentation and do not copy executable code from these projects. Review and preserve the applicable license notice before incorporating substantial external code or text.

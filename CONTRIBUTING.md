# Contributing

Thank you for helping Teach Me become a more useful and trustworthy teacher in Arabic and English.

## Valuable contributions

- A minimal, reproducible teaching failure.
- A correction supported by a direct authoritative source.
- A natural Arabic or English language improvement.
- An accessibility or age-appropriateness improvement.
- An evaluation that measures observable behavior rather than wording.
- A domain teaching pack with qualified review.

## Privacy and rights

Never submit student names, contact information, private transcripts, medical or financial details, or protected curriculum content. Use fictional or heavily minimized examples. Confirm that you are authorized to share every attached artifact.

## Change process

1. Describe the failure and expected behavior.
2. Add or update a reproducible evaluation case.
3. Make the narrowest change that addresses the evidence.
4. Run `python3 scripts/validate.py`.
5. Explain accuracy, safety, language, latency, or maintenance tradeoffs in the pull request.

Global behavior must not change from one user's preference alone. High-stakes domain changes require appropriate specialist review.
